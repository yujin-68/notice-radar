# KNU Notice Radar
**경북대 공지사항 수집 & 맞춤 추천 프로그램**

---

## 한 문장 설명

경북대 학생이 놓치기 쉬운 여러 채널의 공지사항을 자동으로 수집하고, 개인 관심사에 맞게 필터링·추천해주는 CLI 기반 알림 도우미

---

## 풀려는 문제

- 학교 공지사항은 학과별·본부·단과대 등 채널이 분산되어 있어 매번 직접 접속해야 한다.
- 타 단과대 공지여도 공모전·세미나 등 참여 가능한 활동이 있지만 발견하기 어렵다.
- 공지를 놓쳐 신청 기간을 지나치거나 유익한 기회를 모르고 지나가는 경우가 많다.
- 필요한 키워드(장학금, 공모전, AI 등)를 한 번에 검색할 수 있는 통합 창구가 없다.

---

## 핵심 기능

| 구분 | 기능 | 설명 |
|------|------|------|
| 필수 | 공지 크롤링 | 경북대 공지사항 페이지에서 최신 게시물을 자동으로 수집 |
| 추가 1 | 키워드 맞춤 필터 | 사용자가 설정한 관심 키워드(예: 장학금, AI, 공모전)에 해당하는 공지만 추출·표시 |
| 추가 2 | 결과 저장 & 비교 | 이전 실행 결과와 비교해 새로 등록된 공지만 하이라이트하고 텍스트 파일로 저장 |

---

## 예상 사용자

공지사항을 자주 놓치는 경북대 학부생 (주 사용자: 본인)

## 결과물 형태

- **CLI** — 터미널에서 실행하는 텍스트 기반 인터페이스
- **Web** — 핵심 정보만 보여주는 심플한 웹페이지

---

## 사용할 Python 개념

- 변수, 리스트, 딕셔너리
- 함수, 조건문, 반복문
- 파일 입출력 (`open`, `read`, `write`)
- 외부 라이브러리: `requests`, `BeautifulSoup`, `json`

---

## 현재 구현 (Python)

- 엔트리 포인트: `main.py`
- 핵심 로직: `notice_radar.py`
- 설정 파일: `config.json`
  - 기본 관심 키워드: `해외`, `학부연구생`
  - 기본 소스 파일: `url.md` (여기 있는 URL 전체를 순회 수집)

---

## 실행 방법

```bash
pip install -r requirements.txt
python main.py
```

실행 결과:

- `data/latest.json`: 현재 실행 결과
- `data/previous.json`: 이전 실행 결과 백업
- `data/history.jsonl`: 실행 이력
- `result.txt`: 터미널 확인용 텍스트 결과 (`NEW` 포함)

### 웹페이지 실행

```bash
python web_app.py
```

브라우저에서 `http://127.0.0.1:5000` 접속  
(`/?refresh=1`로 수동 새로고침 가능)

웹페이지 표시 기준:

- 제목 키워드 매칭 결과만 표시 (**OR 조건**: 키워드 중 하나라도 포함되면 매칭)
- 날짜 기준 **최신순 정렬**
- 새로 발견된 항목은 `NEW` 태그 표시

## 옵션

```bash
python main.py --keyword 해외 --keyword 학부연구생
python main.py --source-url "https://home.knu.ac.kr/HOME/seeai/"
python main.py --source "학부 공지" --after 2026-06-01 --new-only
python main.py --offline-html "IT대학-전자공학부-인공지능전공_files/index.html"
```
